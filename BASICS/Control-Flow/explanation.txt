Flow control statements often start with a part called the 'condition'
Always followed by a block of code called a clause.

Boolean expressions could all be considered conditions.
A condition is just an expression; it is just a specific name in the context of flow control statements.
Conditions always evaluate to a Boolean value - True or False.
A flow control statement decides what to do based on whether the condition evaluates to True or False.
Almost every flow control statement uses a condition.

Lines of Python code can be grouped together into blocks.
You can tell where a block begins and ends by looking at the indentation of the lines.
